Sensores

Del fenómeno físico a una señal eléctrica: funcionamiento, tipos, características, aplicaciones y simulaciones.

01 · Introducción

¿Por qué estudiar los sensores?

Cuando comencé a estudiar sensores, una idea me ayudó a entenderlos: un circuito electrónico no puede "ver" directamente la temperatura, la luz, la presión o la distancia. Necesita un dispositivo que transforme esa información física en una señal que pueda medir.

Por eso considero que el sensor es uno de los puntos más importantes de un sistema electrónico. Es el enlace entre lo que está ocurriendo en el mundo físico y el procesamiento que realiza un circuito, un microcontrolador o un sistema de control.

En este trabajo relaciono la teoría con ejemplos propios, cálculos y simulaciones. La intención es mostrar no solamente qué es un sensor, sino qué sucede con la señal después de realizar una medición.

Idea central: un sensor convierte una condición física en información que un sistema electrónico puede medir, procesar y utilizar.
02 · Concepto

¿Qué es un sensor?

Un sensor es un dispositivo que detecta una magnitud física, química o ambiental y produce una respuesta que puede utilizarse como información. Dependiendo del sensor, esa respuesta puede ser una variación de voltaje, corriente, resistencia, capacitancia, frecuencia u otra magnitud eléctrica.

Algunas variables que pueden medirse son:

Temperatura

Indica qué tan caliente o frío está un objeto, ambiente o proceso.

Luz

Permite detectar el nivel de iluminación.

Presión

Permite medir la presión de un fluido o gas.

Distancia

Permite determinar qué tan cerca o lejos está un objeto.

Humedad

Permite conocer la humedad del ambiente o de determinados materiales.

Movimiento

Permite detectar desplazamiento, aceleración o presencia.

03 · Principio de funcionamiento

¿Cómo funciona un sensor dentro de un sistema?

Para comprender un sensor es importante no verlo como un elemento aislado. Normalmente forma parte de una cadena de medición.

1. Fenómeno físicoTemperatura, luz, presión, etc.
2. DetecciónEl elemento sensible responde.
3. ConversiónSe obtiene una magnitud eléctrica.
4. AcondicionamientoSe amplifica o filtra la señal.
5. ProcesamientoSe interpreta el valor.
6. AcciónEl sistema muestra, controla o actúa.
Variable física → Sensor → Señal eléctrica → Acondicionamiento → Procesamiento → Acción

Ejemplo propio: ventilación automática

Imaginé una habitación donde quiero activar un ventilador cuando la temperatura aumente demasiado. El sensor mide la temperatura y genera una señal eléctrica. Esa señal llega a un controlador que compara la temperatura medida con un valor de referencia.

Si la temperatura supera el límite definido, el sistema puede activar el ventilador. Así se forma una cadena sencilla de medición y control.

Tipos de sensores

Según la variable

Activos y pasivos

Pasivos: su comportamiento puede representarse mediante cambios en una propiedad eléctrica, como la resistencia. Una LDR es un ejemplo.

Activos: pueden generar una señal eléctrica a partir del fenómeno medido, según el principio físico utilizado. Un termopar es un ejemplo clásico.

Un mismo sensor puede clasificarse de diferentes maneras según el criterio utilizado.

05 · Calidad de medición

Características importantes

Rango

Intervalo de valores dentro del cual el sensor puede realizar su medición especificada.

Sensibilidad

Cuánto cambia la salida cuando cambia la magnitud de entrada.

Resolución

Menor cambio que el sistema puede distinguir.

Precisión

Qué tan cercanas están las mediciones al valor de referencia.

Tiempo de respuesta

Qué tan rápido responde ante un cambio.

Linealidad

Qué tan cercana es la relación entrada-salida a una relación lineal.

Mi análisis

Al escoger un sensor no basta con preguntar qué mide. También debo revisar rango, sensibilidad, rapidez, resolución, ambiente de trabajo y características de la señal que necesito entregar al sistema.

06 · Simulación 1

Sensor de temperatura

Para desarrollar un ejemplo sencillo planteé un sensor ideal cuya salida cambia linealmente de 0 V a 5 V cuando la temperatura cambia de 0 °C a 100 °C.

Vout = (5 V / 100 °C) · T

La sensibilidad de este modelo es:

S = 5/100 = 0,05 V/°C = 50 mV/°C

Simulación interactiva

Ejemplo propio

Si selecciono 70 °C:

V = 0,05 · 70 = 3,5 V

Según este modelo, el sistema entrega 3,5 V. Es un modelo didáctico; un sensor real tendría características, tolerancias y errores propios.

07 · Simulación 2

Sensor de luz: LDR

La LDR o fotoresistencia cambia su resistencia dependiendo de la iluminación. Para obtener una tensión que pueda leer un circuito, puedo colocarla en un divisor de tensión.

Vout = Vcc · R2 / (R1 + R2)

Simulación interactiva del divisor con sensor

Lo que aprendí con este ejemplo

El sensor no necesariamente entrega directamente un voltaje. Puede cambiar una propiedad eléctrica y necesitar una etapa adicional para convertir ese cambio en una señal fácil de medir. En este caso, el divisor de tensión realiza esa conversión.

08 · Simulación 3

Sensor de distancia por ultrasonido

Un sensor ultrasónico puede determinar una distancia midiendo el tiempo que tarda una onda en viajar hasta un objeto y regresar como eco.

d = (v · t) / 2

Para el ejemplo uso aproximadamente 343 m/s como velocidad del sonido a temperatura ambiente.

Simulación interactiva de tiempo de vuelo

Ejemplo propio

Para 100 cm, es decir 1 m:

t = 2(1)/343 ≈ 0,00583 s = 5,83 ms

El sensor debe medir ese intervalo de ida y vuelta para estimar la distancia.

09 · Electrónica asociada

¿Qué ocurre después del sensor?

La señal obtenida por un sensor muchas veces necesita acondicionamiento antes de entrar a un sistema de control.

SensorObtiene la variable.
AmplificadorAumenta una señal pequeña.
FiltroReduce componentes no deseados.
ADCConvierte señal análoga a datos digitales.
ControladorProcesa la información.
ActuadorRealiza la acción.

Ejemplo integrado

Imaginé un sistema de control de temperatura:

Temperatura → Sensor → Amplificador → ADC → Microcontrolador → Ventilador

Esta cadena muestra que medir es solamente el primer paso. Después hay que adaptar, procesar e interpretar la señal.

10 · Aplicaciones

¿Dónde se utilizan?

Automatización industrial

Temperatura, presión, nivel, flujo y posición para supervisar procesos.

Robótica

Distancia, obstáculos, orientación, aceleración y movimiento.

Domótica

Iluminación, temperatura, presencia y seguridad.

Automóviles

Numerosos sensores supervisan variables del motor, seguridad y funcionamiento.

Medicina

Instrumentos médicos utilizan sensores para obtener diferentes variables fisiológicas.

Electrónica de consumo

Teléfonos y dispositivos incorporan sensores de movimiento, luz y proximidad.

11 · Análisis propio

Lo que comprendí del tema

Al desarrollar estos ejemplos comprendí que decir "un sensor mide una variable" es correcto, pero no explica todo el proceso. Para que una medición sea útil necesito considerar cómo responde el sensor, qué señal produce y qué circuito recibirá esa señal.

También entendí que no existe un sensor universal. La elección depende de la variable, el rango, la sensibilidad, la velocidad de respuesta, el ambiente y la forma en que el sistema procesará la información.

Las simulaciones me ayudaron a ver esta relación. En temperatura, una variación de la variable produjo una variación proporcional de la señal. En la LDR, un cambio de resistencia modificó el voltaje del divisor. En el ultrasónico, un tiempo de vuelo permitió relacionar una magnitud temporal con una distancia.

Los tres ejemplos muestran que detrás de cada sensor existe un principio físico diferente. Lo que tienen en común es que transforman información del mundo real en una forma que puede ser utilizada por un sistema electrónico.

12 · Cierre

Conclusiones propias

1. Comprendí que el sensor es el vínculo entre una variable física y el sistema electrónico.

2. Aprendí que diferentes sensores utilizan principios diferentes: cambios de resistencia, generación de señales eléctricas o medición del tiempo de vuelo, entre otros.

3. Entendí que rango, sensibilidad, resolución, precisión y tiempo de respuesta son características necesarias para seleccionar un sensor.

4. La LDR me permitió comprender cómo una variación de resistencia puede convertirse en una tensión mediante un divisor de voltaje.

5. El modelo de temperatura me permitió relacionar una variable física con una señal y calcular la sensibilidad.

6. El ejemplo ultrasónico me permitió entender cómo el tiempo de una señal puede utilizarse para calcular una distancia.

7. Finalmente, comprendí que el sensor es solamente una parte del sistema: después de medir, normalmente es necesario acondicionar, procesar e interpretar la señal.

Reflexión final: Para mí, estudiar sensores cambió la forma de observar los circuitos electrónicos. Ahora puedo entender que detrás de una acción automática existe una cadena de medición: algo sucede físicamente, un sensor lo detecta, una señal representa esa información y un sistema electrónico decide qué hacer con ella.
